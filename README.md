# تمرین ۴: کاربرد CLIP — جستجوی معنایی و تفسیر هوشمند داده‌های پزشکی

تشخیص **Zero-Shot** درجه‌ی رتینوپاتی دیابتی در تصاویر شبکیه (دیتاست DeepDRiD) و **جستجوی متن ↔ تصویر** با مدل CLIP،
با استفاده از **جمله‌های توصیفی پزشکی** به جای برچسب‌های ساده. هیچ آموزشی انجام نمی‌شود و کل نوت‌بوک روی CPU در حدود ۳ دقیقه اجرا می‌شود.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `ADL_HW4_CLIP_Medical.ipynb` | نوت‌بوک اصلی؛ کامنت‌گذاری شده و همه‌ی سلول‌ها **اجرا شده‌اند** |
| `report/ADL_HW4_Report.docx` | گزارش (نسخه‌ی Word) |

## اجرای مرحله به مرحله

۱. نصب کتابخانه‌ها (Python 3.10 یا جدیدتر):

```bash
pip install -r requirements.txt
```

۲. اجرای نوت‌بوک (در Jupyter: `Kernel → Restart & Run All`، یا در ترمینال):

```bash
jupyter nbconvert --to notebook --execute --inplace ADL_HW4_CLIP_Medical.ipynb
```

در اولین اجرا دو چیز خودکار دانلود می‌شود (به اینترنت و `git` نیاز است):

- **دیتاست DeepDRiD** در پوشه‌ی `DeepDRiD/` (فقط تصاویر regular fundus بخش training و validation، حدود ۱٫۷ گیگابایت) از
  [مخزن رسمی دیتاست](https://github.com/deepdrdoc/DeepDRiD)
- **وزن‌های CLIP ViT-B/32** در پوشه‌ی `weights/` (حدود ۶۰۰ مگابایت) از صفحه‌ی Release پروژه‌ی
  [open_clip](https://github.com/mlfoundations/open_clip)

این دو پوشه به دلیل حجم زیاد در مخزن قرار نگرفته‌اند (`.gitignore`). اگر آن‌ها را دستی دانلود می‌کنید، ساختار باید این‌طور باشد:

```
DeepDRiD/regular_fundus_images/regular-fundus-training/{regular-fundus-training.csv, Images/<patient>/<image>.jpg}
DeepDRiD/regular_fundus_images/regular-fundus-validation/{regular-fundus-validation.csv, Images/<patient>/<image>.jpg}
weights/vit_b_32-quickgelu-laion400m_e32-46683a32.pt
```

## روش

- **داده:** ۱۶۰۰ تصویر شبکیه از ۴۰۰ بیمار با درجه‌ی رتینوپاتی دیابتی ۰ تا ۴. بخش validation رسمی (۴۰۰ تصویر) به‌عنوان **پرس‌وجو** و
  بخش training رسمی (۱۲۰۰ تصویر) به‌عنوان **گالری** استفاده شده است (بدون بیمار مشترک).
- **مدل:** CLIP ViT-B/32 از کتابخانه‌ی `open_clip` با وزن‌های LAION-400M (با `WEIGHTS = "openai"` در سلول تنظیمات می‌توان وزن‌های اصلی
  OpenAI را بارگذاری کرد).
- **پرامپت‌ها:** (A) برچسب ساده `a photo of ...`، (B) یک جمله‌ی توصیفی پزشکی برای هر درجه، (C) مجموعه‌ای از سه جمله‌ی توصیفی برای هر درجه.
- **تشخیص Zero-Shot:** شباهت کسینوسی تصویر با جمله‌ها × ۱۰۰ و سپس `softmax` برای احتمال هر جمله.
- **جستجوی معنایی:** متن → تصویر (۷ توصیف متنی روی گالری) و تصویر → تصویر (k-NN)، به‌علاوه‌ی Linear Probe به‌عنوان مرجع نظارت‌شده.

## نتایج (۴۰۰ تصویر پرس‌وجو)

| روش | Accuracy | Balanced Acc. | Quadratic κ | AUC بیمار/سالم |
|---|---|---|---|---|
| Zero-Shot — برچسب ساده | 14.3% | 13.0% | −0.02 | 0.518 |
| Zero-Shot — جمله‌ی توصیفی پزشکی | **44.8%** | **26.1%** | **0.23** | 0.691 |
| Zero-Shot — مجموعه‌ی توصیف‌ها | 43.8% | 20.5% | 0.12 | **0.725** |
| k-NN تصویر → تصویر (با برچسب گالری) | 54.5% | 37.5% | 0.48 | 0.842 |
| Linear Probe (با برچسب گالری) | 63.5% | 46.5% | 0.71 | 0.905 |

جستجوی متن → تصویر: میانگین Precision@5 برابر **۰٫۵۱** در مقابل Base rate برابر ۰٫۲۸.

توصیف‌های پزشکی دقت را نسبت به برچسب ساده سه برابر می‌کنند، اما CLIP عمومی درجه‌های ۱ و ۲ را تشخیص نمی‌دهد و دقت آن فقط کمی بالاتر از
حدس کلاس اکثریت (۴۳٫۵٪) است؛ تحلیل کامل در گزارش و بخش ۷ نوت‌بوک آمده است.
